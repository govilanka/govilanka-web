# Govi Lanka Trading — Modern Website

A responsive static website concept for Govi Lanka Trading (Pvt) Ltd, built with plain HTML, CSS and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.

No build tools or packages are required. Google Fonts and the photography used in the design load from the internet.

## Project structure
- `index.html` — page content and semantic markup
- `css/style.css` — responsive layout, styling and image treatments
- `js/main.js` — mobile navigation, active section navigation and footer year

## Before publishing
- Confirm all company details, product availability and contact information.
- Replace the remote image URLs with approved company photography where available.
- Add a privacy policy if you later introduce forms, analytics or tracking.
